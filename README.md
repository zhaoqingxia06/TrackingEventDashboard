# User Behavior Tracking

帮助产品经理梳理产品上线后需要监测的数据指标，按 **用户规模 → 使用频率 → 功能行为与流程转化** 组织，并将指标落实为统计口径、埋点采集需求和看板图表。

技能文件：[SKILL.md](user-behavior-tracking/SKILL.md)；调用标识：`$user-behavior-tracking`。

## 数据指标与统计口径

以下表格覆盖 Skill 涉及的监测指标，并将“人数与次数”“结果与分布”等组合项展开。它是按需选用的指标目录，不要求每个产品全部采集；表中对未明确细节给出的口径属于建议，落地前应确认。

统一约定：**U** 为约定用户标识（账号、VID或设备，前后一致）；**S** 为会话ID；**T** 为任务/流程实例ID。“人数”均按U去重，不等同于真实自然人数；“次数”先按事件唯一ID排除重复上报。默认按业务时区的事件发生时间统计，建议明确为 Asia/Shanghai；所有比例分母为0时显示“—”，不得伪记为0%。

| 模块 | 数据指标 | 统计粒度/窗口 | 统计口径 |
| --- | --- | --- | --- |
| 用户规模 | 日活跃用户 DAU | 日 | 当天发生指定有效使用事件的去重U数。 |
| 用户规模 | 月活跃用户 MAU | 自然月 | 月内发生有效使用事件的去重U数，不累加DAU；当月标注截至日期。 |
| 用户规模 | 滚动30日活跃用户 | 日 | 统计日及前29天发生有效使用事件的去重U数，与自然月MAU分开。 |
| 用户规模 | 新增用户 | 日 | 全历史首次发生约定使用事件的日期为当天的去重U数；历史不足称首次观测。 |
| 用户规模 | 累计用户 | 截至每日 | 从明确统计起点至当天发生过约定使用事件的去重U数；不累加DAU。 |
| 用户规模 | 当日新增活跃用户 | 日 | 当日活跃集合中，首次有效使用日期为当天的U数。 |
| 用户规模 | 当日老活跃用户 | 日 | 当日活跃集合中，首次有效使用日期早于当天的U数。 |
| 用户规模 | 次日留存率 | 新增日队列 | D日新增U中在D+1再次发生约定回访事件的U数÷D日新增U数。 |
| 用户规模 | 第三日留存率 | 新增日队列 | D日新增U中在D+3再次发生约定回访事件的U数÷D日新增U数；非三日内回访。 |
| 用户规模 | 第七日留存率 | 新增日队列 | D日新增U中在D+7再次发生约定回访事件的U数÷D日新增U数。 |
| 用户规模 | 周留存率（按需） | 周队列 | 建议按自然周：W周首次使用U中，在W+1周再次使用的U数÷W周新增U数；采用其他周窗口须另注。 |
| 用户规模 | 各功能使用人数 | 日/所选周期 | 周期内发生指定功能使用事件的去重U数；跨功能可重叠。 |
| 用户规模 | 功能渗透率 | 日/所选周期 | 同一资格用户群中使用该功能的U数÷同期具备该功能使用资格的活跃U数。 |
| 用户规模 | 持续开启率（按需） | 队列+窗口 | 建议：基准时点已开启的U中，在完整观察窗口内持续保持开启的U数÷基准已开启U数；缺失状态列未知。 |
| 用户规模 | 有效运行天数（按需） | 用户×周期 | 每U在周期内满足约定有效后台运行条件的去重日期数；跨午夜运行按日切分。 |
| 使用频率 | 使用总次数 | 日/所选周期 | 指定有效使用事件去重后的发生次数；一次使用对应哪个事件需事先约定。 |
| 使用频率 | 人均使用次数 | 日/所选周期 | 同周期有效使用总次数÷发生该使用行为的去重U数。 |
| 使用频率 | 使用频率分布人数及占比 | 日 | 按U汇总当日使用次数，再分1、2–5、6–10、11及以上；各组人数÷该日使用U数。 |
| 使用频率 | 会话次数 | 日/所选周期 | 满足约定会话起止规则的去重S数；默认按会话开始日归属。 |
| 使用频率 | 会话用户数 | 日/所选周期 | 发生至少一次有效会话的去重U数。 |
| 使用频率 | 人均会话次数 | 日/所选周期 | 有效会话次数÷发生有效会话的去重U数。 |
| 使用频率 | 月内活跃天数及分布 | 用户×自然月 | 每U月内有效使用的去重日期数；按天数分组统计人数及其占月活用户比例。 |
| 使用频率 | 相邻使用间隔及分布 | 相邻使用对 | 同U相邻有效使用时间差；建议按后一次使用日期入组，向前读取上次记录，无前次记录不当作0。 |
| 使用频率 | 有效使用总时长 | 日/所选周期 | 汇总约定有效运行区间时长，明确前后台范围；跨日按实际时间切分，重叠区间不重复累计。 |
| 使用频率 | 单次平均使用时长 | 日/所选周期 | 完整、有效的单次使用时长之和÷对应有效使用次数；未结束及异常记录单列。 |
| 使用频率 | 单次使用时长分布次数及占比 | 日/所选周期 | 按有效单次时长落入互斥区间统计次数；区间次数÷有效单次使用总次数。 |
| 使用频率 | 会话成功产出总量 | 日/所选周期 | 按S关联成功发送、查看或完成的对象数量，明确按内容还是成功动作计数，排除重复上报。 |
| 使用频率 | 每次会话平均产出数量 | 日/所选周期 | 有效会话内成功产出总量÷同批有效会话次数；分母含零产出会话。 |
| 使用频率 | 会话产出数量分布 | 日/所选周期 | 先按S统计成功产出数量，再按0、1、2等互斥区间统计会话数及占比。 |
| 使用频率 | 各小时使用人数 | 0–23小时 | 按约定时区取事件小时；跨多日聚合时，每小时对整个日期范围去重U，若取日均须另行命名。 |
| 使用频率 | 各小时使用次数 | 0–23小时 | 所选日期范围内各小时有效使用事件次数之和；日均次数需除以明确的完整天数。 |
| 使用频率 | 后台开启人数 | 日 | 当天发生关闭→开启状态变更的去重U数；与全天已开启用户数区分。 |
| 使用频率 | 后台开启次数 | 日 | 关闭→开启状态变更的有效次数；重复点击但状态未变不算开启。 |
| 使用频率 | 后台触发人数 | 日 | 当天发生至少一次指定后台识别/触发事件的去重U数。 |
| 使用频率 | 后台触发次数 | 日 | 按独立触发ID或约定去重规则统计有效触发次数。 |
| 使用频率 | 通知送达人数 | 日 | 收到至少一次可观测送达通知的去重U数；只上报发送时只能命名发送人数。 |
| 使用频率 | 通知送达次数 | 日 | 按通知ID及约定终端范围去重的送达次数；同一通知重试不重复计数。 |
| 使用频率 | 分类型通知人数与次数 | 日 | 按声音/通知类型分别计算送达人数和次数；分类人数不可相加为总人数。 |
| 功能行为 | 入口曝光人数 | 日 | 入口满足约定可见曝光条件的去重U数。 |
| 功能行为 | 入口点击人数 | 日 | 点击指定入口的去重U数；点击率计算时限于对应曝光队列。 |
| 功能行为 | 入口点击次数 | 日 | 指定入口有效点击事件次数，按事件ID排除重复上报。 |
| 功能行为 | 入口点击率 | 曝光队列+窗口 | 同一曝光用户群中，在指定窗口内点击入口的U数÷该曝光群U数。 |
| 功能行为 | 关键按钮/关键项点击人数 | 日 | 按具体按钮或项分别统计点击的去重U数。 |
| 功能行为 | 关键按钮/关键项点击次数 | 日 | 按具体按钮或项分别统计有效点击事件次数；用户主动重复点击计入。 |
| 功能行为 | 关键操作人均点击次数 | 日 | 该操作点击次数÷发生该操作的去重U数。 |
| 功能行为 | 漏斗各步骤人数/任务数 | 起点队列+窗口 | 对同一入组U或T，按顺序及窗口关联步骤；明确用户或任务漏斗，跨日任务保持关联。 |
| 功能行为 | 步骤转化率 | 起点队列+窗口 | 从第i步按规则到达第i+1步的实体数÷到达第i步的实体数；实体为U或T且前后一致。 |
| 功能行为 | 整体完成率 | 起点队列+窗口 | 同一起点队列中按流程完成终点的实体数÷进入起点的实体数。 |
| 功能行为 | 步骤流失人数/任务数 | 窗口完整后 | 到达第i步但未在约定窗口内到达下一步的实体数；未满窗口列待观察。 |
| 功能行为 | 步骤流失率 | 窗口完整后 | 步骤流失实体数÷到达第i步的实体数；未知原因不可直接判为体验流失。 |
| 功能行为 | 分支路径次数及占比 | 所选周期/队列 | 按T或路径实例记录分支选择次数÷全部同口径分支选择次数；多次选择与最终路径分开。 |
| 功能行为 | 执行成功用户数与任务次数 | 所选周期 | 按最终结果为成功的T去重计次数，并对关联U去重计人数；同T重试不重复计最终结果。 |
| 功能行为 | 执行失败用户数与任务次数 | 所选周期 | 按最终结果为失败的T去重计次数，并对关联U去重计人数；重试过程失败可另列尝试级指标。 |
| 功能行为 | 取消用户数与任务次数 | 所选周期 | 按可观测用户取消结果的T去重计次数、关联U计人数；不能将所有退出推断为取消。 |
| 功能行为 | 超时用户数与任务次数 | 所选周期 | 按预设超时阈值判定且最终状态明确的T计次数、关联U计人数；与失败分类关系须明确。 |
| 功能行为 | 各失败/异常原因次数 | 所选周期 | 按错误码归类并按异常实例去重计数；按任务最终原因统计时每T只能归入一个最终原因。 |
| 功能行为 | 各失败/异常原因占比 | 所选周期 | 该原因异常次数÷全部同口径异常次数；不是除以全部任务，分母必须标注。 |
| 功能行为 | 各原因受影响用户数 | 所选周期 | 发生该错误原因的去重U数；同U可跨原因重叠。 |
| 功能行为 | 参数选项选择次数及占比 | 提交事件周期 | 读取有效提交时最终选项；每选项提交次数÷该参数有效提交总次数，缺失/不适用单列；多选不要求占比和为100%。 |
| 功能行为 | 内容查看人数与次数 | 所选周期×内容ID | 按内容ID统计有效查看事件次数和去重U数；有效查看条件需约定。 |
| 功能行为 | 内容搜索人数与次数 | 所选周期×内容ID | 明确按提交搜索、搜索命中或点击结果统计；逐内容用可关联内容ID事件计次数及去重U，不能把搜索请求直接归给每个结果。 |
| 功能行为 | 内容收藏人数与次数 | 所选周期×内容ID | 按未收藏→收藏成功事件计次数及去重U数；取消收藏另记，累计收藏状态不可与新增收藏混称。 |
| 功能行为 | 任务执行耗时 | 任务 | 同T执行结束时间－真正开始执行时间；按成功、失败分开，进行中任务单列，重试与排队计时规则明确。 |
| 功能行为 | 任务平均耗时与耗时分布 | 所选周期 | 有效完成任务耗时之和÷同批任务数，并按互斥耗时区间计任务数及占比；按约定结束日归属。 |
| 功能行为 | 输入量×耗时分布 | 所选周期 | 每T关联提交时输入字数等输入量及耗时，按两个维度分桶统计任务数；输入边界遵守实际限制。 |
| 功能行为 | 配置后实际开启人数与比例 | 完成配置队列+窗口 | 配置成功群中在约定窗口实际开启的U数÷该群U数；若按配置对象计则全程使用对象ID。 |
| 功能行为 | 配置后实际触发人数与比例 | 完成配置队列+窗口 | 同一配置成功群在窗口内获得对应功能/对象触发的U数÷该群U数；不混入无关对象触发。 |
| 功能行为 | 配置后实际获得结果人数与比例 | 完成配置队列+窗口 | 同一配置成功群在窗口内获得约定有效结果的U数÷该群U数；明确结果是送达、查看还是成功产出。 |

## 口径落地要求

- **有效使用与成功完成**：针对具体产品绑定事件，分别定义进入、点击、真正执行、成功和实际获得结果；不得互相替代。
- **新增与累计**：优先使用完整历史判定首次；筛选版本、渠道时，须说明是在全局首次使用后分组，还是分组内首次。日/月人数均须周期去重，不能跨天直接相加。
- **留存与转化**：固定入组用户群、起点、目标事件、窗口和去重单位；只展示观察完整的队列。配置回访、使用回访及持续运行分别命名。
- **会话与时长**：明确开始、结束、退出、崩溃、断线、超时和跨日处理规则；说明完整记录的筛选范围及排除数量，避免把未结束当作0秒。
- **结果与异常**：任务最终结果可互斥，用户可能经历多种结果，各结果人数不可直接相加。保留未知、进行中及缺失分类，不凭数据缺失推断流失原因。
- **分布与图表**：区间不重叠、不遗漏，明确零值和最大边界；展示次数时以次数为占比分母。所有图表附标题、单位、统计口径和数据截止时间。
- **可计算性**：本仓库 Skill 提供指标设计规则，并非已执行SQL或真实数据结果。是否能计算取决于实际事件、身份、关联ID及历史覆盖。

## 所需采集字段

按指标选择必需字段：用户标识、事件发生时间、事件唯一ID、事件名称/ID、产品版本、功能/页面/控件标识；按需补充会话ID、任务ID、内容ID、配置对象ID、来源渠道、提交时最终参数、输入量、开始/结束时间、运行状态、最终结果、错误码、触发ID及通知ID/送达状态。具体字段名和枚举应以实际埋点协议为准。
